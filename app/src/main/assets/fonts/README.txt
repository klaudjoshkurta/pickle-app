Google Sans font resources

Source: https://github.com/google/fonts/tree/main/ofl/googlesans
License: GoogleSans-OFL.txt
Trademark information: GoogleSans-TRADEMARKS.md

Bundled static weights: 400, 500, 600, 700, normal and italic.
Generated from the official variable fonts using fontTools, with optical size 18
and grade 0. Static instances support Android API 24 and above.
Subsets retain Latin, Greek, Cyrillic, punctuation, and symbols (U+0000–052F,
U+1E00–1FFF, U+2000–2BFF) for the app's English and Greek locales.
